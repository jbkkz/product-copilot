- Documentation: `docs/plugin-bundling.md` records why the Claude Code plugin does not bundle the `requivo` CLI (#94). It states what the plugin spec measurably supports today — a plugin-root `bin/` really is on the Bash tool's `PATH`, and a first-run bootstrap really would work — and why neither is shipped: `SessionStart` is the only automatic hook and it cannot ask the user, so an automatic bootstrap is a silent network install by construction. Installing `requivo` stays a separate step.
