- The Claude Code plugin's `homepage` is now `https://requivo.com` in both the plugin
  manifest and the marketplace entry, replacing a `blob/main/...` link to the plugin's own
  README (#125). A marketplace catalog shows one homepage per entry, and the submission
  already carries the repository in a field of its own — so this is the only slot that can
  point somewhere other than a source tree, and a blob URL on a branch breaks when the file
  moves. `repository` is unchanged. The plugin still ships its README, which is what a
  reader wants *after* installing rather than before.
