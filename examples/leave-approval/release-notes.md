# Leave Request Approval Workflow — v1.0

> Release notes — generated by Requivo

Leave requests no longer depend on email chains that can stall or get lost. Every request now follows a clear approval path — manager, then HR when needed — and always ends in a recorded decision, giving HR and employees a reliable, auditable record of who approved what and when.

## What's new

- Submit a leave request and know it will always reach a decision — no more emails left unanswered
- Routine requests get a fast manager approval; longer requests (over 10 days) or requests exceeding available balance are automatically routed to HR for sign-off
- Managers can delegate approval to a named substitute while away, so requests don't wait on one person
- If a request sits unanswered for 3 working days with no backup approver, it automatically escalates to HR — nothing stalls silently
- Cancel an approved request up to 48 hours before it starts, with your leave balance restored automatically the same night
- Leave balances stay in sync with the existing HR system every night, and any request submitted during a temporary mismatch is still processed (flagged for HR review) rather than blocked
- Every approval, override, escalation and cancellation is logged in a complete audit trail, retained for 5 years to support works-council and compliance requirements

## Not included yet

- This pilot uses a single shared approval workflow and rule set — different rules per department or country are not yet supported
- The existing HR system remains the source of truth for leave balances during the pilot; what happens to this dependency afterward is still to be decided
- The system enables and records decisions, but it cannot by itself stop managers from continuing to approve leave by email — a complementary policy (e.g., payroll only recognizing system-recorded approvals) is recommended alongside the rollout
- Formal test scenarios for acceptance are based on the agreed success measures (100% recorded decisions, no unresolved month-end mismatches, under 2-day turnaround, full manager adoption) but have not yet been written up as detailed test cases

## Before you start

- For the pilot to succeed, managers need to fully stop approving leave by email — consider a clear internal communication or policy backing this up.
- HR will need to review and resolve any nightly balance mismatches each morning; requests submitted during a mismatch window proceed against the last-known balance and are flagged as at-risk until resolved.
- A decision is needed before the pilot ends on whether leave balance ownership moves fully into this platform or the nightly sync with the legacy HR system continues long-term.
